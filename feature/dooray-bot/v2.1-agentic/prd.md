# PRD — @clauday 에이전트 강화 (v2.1)

> 상세 기획·실측 근거·목업: `docs/planning/clauday-agent-plan.md`, `docs/mockups/agent/dooray-agent-flow.html`
> 이 문서는 요구사항과 사용자 결정의 원본이다. 설계 근거는 `adr.md`, 진행은 `plan.md`, 변경 내역은 `impl-log.md`.

## 1. 문제

v2.0.6 의 @clauday 는 "원격 트리거 1회 + 최종 답 1회" 였다.

| 공백 | 결과 |
|---|---|
| 응답을 ```` ```md ```` 로 감싸 1500자에서 자름 | 줄번호 코드블록, 링크 클릭 불가, 중간 잘림 (운영 채널 실사용 1건에서 확인) |
| 회신에 "사용 도구" 꼬리말과 로컬 경로 | 내부 정보 노출 |
| 글타래에서 불러도 원글을 못 읽음 | 운영 채널 글타래 첫 답글의 ~40% 가 원글 없이 뜻이 안 통함 |
| `--dangerously-skip-permissions` | 위험 동작을 사람이 볼 기회가 없음 |
| 진행 상황 없음 | 30분 작업 동안 침묵 |
| TUI 직접 입력 턴도 두레이로 회신 | 사적인 대화 유출 |
| 소켓이 끊긴 동안 온 멘션 유실 | 외출 중 사용 불가 |

## 3. 수락 기준

- AC1 회신에 ```` ```md ```` 감싸기·도구 꼬리말·로컬 경로가 없다. 헤더 ▍, 리스트 •, 링크·인라인 코드·언어 코드블록은 살아 있다
- AC2 긴 답(600자 초과·표·긴 코드)은 완료 카드가 글타래 원글, 전문은 그 글타래에 2,000자 이하 조각으로. 글타래 안 멘션이면 같은 글타래에 카드 + 조각
- AC3 진행 메시지 1개가 `⏳ 작업 중 · m:ss · 단계` 로 갱신되고 끝나면 `✅ 완료 · m:ss ↓`
- AC4 글타래 멘션은 원글 + 글타래 전체를 읽는다. 첨부 이미지는 채널 폴더로 내려받아 경로를 준다. 비밀값은 가린다
- AC5 TUI 에 직접 친 턴은 두레이로 회신하지 않는다
- AC6 (D11) 평소 도구는 묻지 않는다. 위험 목록만 채널 승인 카드 → 내 답장으로 결정. 9분 무응답·카드 송신 실패는 거절. "항상 승인" 은 채널별로 기억되어 재시작 뒤에도 유지. 멘션 턴이 끝난 뒤 백그라운드로 이어진 작업의 위험 동작도 같은 자리로 묻고, 그 작업이 끝나 나온 응답도 같은 자리로 회신한다
- AC7 충전 중 + 봇 연결이면 잠자기·App Nap 을 막는다. 소켓 재연결 시 그사이 내 멘션을 찾아 실행(3시간 초과는 안내만). 연결 이력이 파일로 남고 설정 화면에 끊김 횟수가 보인다
- AC8 채널 폴더에 `dooray-reply`·`internal-systems` 스킬이 동기화된다
- AC9 설정에서 권한 모드(두레이 승인 / 자율)와 깨어 있기를 바꿀 수 있고, 온보딩 투어에 설명이 있다

## 4. 비목표
