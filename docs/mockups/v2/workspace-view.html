임임태원 · Android iOS · 마감 8/12 (수) · 등록됨

메신저/메일/프로젝트 알림을 사용자가 카테고리별로 제어할 수 있는 푸시 알림 설정 화면을 신규로 구현합니다. Android와 iOS 공통 스펙이며, 설정 모델은 KMP 공유 모듈에 두고 각 플랫폼은 UI만 구현합니다.

기존에는 전체 on/off 단일 토글만 제공되어 "메일 알림만 끄고 싶다"는 VOC가 반복적으로 들어왔습니다. 이번 개편으로 카테고리 단위 제어와 방해금지 시간대를 함께 제공합니다.

  • ✓ 알림 카테고리 목록/스펙 확정 (메신저·메일·프로젝트·캘린더)
  • 카테고리별 on/off 토글 UI
  • 방해금지 시간대 설정 (요일 + 시간 범위)
  • 설정값 서버 동기화 API 연동

디자인 시안은 Figma Push-Settings-v2 페이지 기준. 접근성(VoiceOver/TalkBack) 라벨 필수.
